# Support

ARIA is research code provided without warranty under the accompanying
[license](LICENSE).

- Use a GitHub bug report for reproducible implementation defects.
- Use a GitHub discussion or question issue for setup and protocol questions,
  if those features are enabled by the repository owner.
- Follow [SECURITY.md](SECURITY.md) for vulnerabilities; do not disclose them
  in a public issue.

Include the Git commit, platform, Python/CUDA versions, command, compression
ratio, checkpoint metadata, and relevant artifact-schema versions. Remove
credentials, private paths, personal data, proprietary datasets, and model
tokens before posting.

The maintainers cannot provide model weights, third-party datasets, KILT
corpora, or licenses on behalf of their owners.
