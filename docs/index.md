# ARIA documentation

ARIA is a two-phase latent-compression RAG research implementation derived
from Apple CLaRa. It implements the paper's score-conditioned memory allocation
and memory-conditioned retrieval path using CFRS, ACR, and MTFRL.

Start with [Getting started](getting_started.md) and the
[reproducibility checklist](reproducibility.md), then read the compact
[method contract](method.md), [data](data.md), [training](training.md),
[inference](inference.md), and [evaluation](evaluation.md) guides. Repository
governance and release details are in
[CONTRIBUTING](../CONTRIBUTING.md), [SECURITY](../SECURITY.md), and the
[changelog](../CHANGELOG.md). Maintainers must complete the
[public release checklist](release.md) before publishing a repository or
package snapshot.
